# Лабораторна робота №2

Використання графіки у HTML-документах.

Відкрийте `HTML/index.html` у браузері. Між завданнями можна переходити через меню. Сервер та встановлення залежностей не потрібні.

Локальну копію початкових файлів першої лабораторної збережено в `lab1-original/`; до репозиторію вона не додається.

| Файл | Завдання |
| --- | --- |
| `HTML/PieshkoLab02-3.htm` | Сторінка першої лабораторної з власною емблемою |
| `HTML/PieshkoLab02-4.htm` | Сторінка групи 305-ТN з фоновим зображенням |
| `HTML/PieshkoLab02-5.htm` | Фотографії з підписами та атрибутами `ALT`, `BORDER`, `HEIGHT`, `WIDTH` |

Вихідну емблему надав автор. З неї збережено `image/logo.bmp`, а потім виконано конвертацію BMP → JPG у `image/logo.jpg`. Малюнок не перемальовувався.

Фон сторінки групи — надане автором зображення `какащьке.jpg` у корені проєкту. Зображення зберігаються локально. На сторінці про себе залишено підключення шрифту Google Fonts з першої лабораторної; без інтернету працює запасний моноширинний шрифт.

Атрибути `BACKGROUND`, `BORDER`, `ALIGN`, `HSPACE`, `VSPACE` залишено для відповідності навчальному завданню. Оформлення й адаптацію до невеликих екранів задано в `css/style.css`.
